## 按钮与数据流

| 界面入口 | 实际操作与保存位置 | 检查结果 / 修正 |
| --- | --- | --- |
| 设置 / 保存设置 | 在独立弹窗保存仓库、分支、选项和可选 PAT 密文到当前来源的 localStorage | 保存关闭弹窗；取消 / Esc 恢复原选项并清空凭证输入；首次设置或切换仓库 / 分支后自动读取账号，不执行远端写入；Pages 隐藏并禁用本地文件写入 |
| 解锁 / 立即锁定 / 删除 PAT / 清除设置 | 密码解锁到本页内存；移除内存凭证或已存设置 | 密码和明文 PAT 不进入存储；错误密码、篡改和存储失败有明确错误；离开页面锁定 |
| 打开页面 / 刷新账号 | 默认读取已配置仓库 / 分支的最新账号 | 页面刷新后先弹窗解锁 PAT，再自动加载；未编辑时无需覆盖确认，有账号修改（含删空表格）或 PushPlus 草稿时先确认；加载失败保留表格；状态显示在表格旁；不自动恢复本地草稿 |
| 添加 / 编辑 / 删除账号 | 更新内存草稿，搜索与分页不改变保存范围 | 删除、身份变更、清除 CF 引用标记为需要替换；浏览器草稿保留此标记和已分配变量名，防止刷新后复用已删除账号的 Secret 名称 |
| 剪贴板 / 站点抓取书签 | 用户确认后生成站点系统令牌，再填入编辑弹窗 | 初始 GitHub 加载或取消解锁后再打开书签导入弹窗，避免被加载操作关闭；取消弹窗不直接更改表格；生成令牌可能使旧令牌失效 |
| 批量导入 JSON | 校验全部账号后合并或替换内存草稿 | 无效账号或变量名冲突时不留下部分导入结果；替换先确认 |
| 生成配置 / 复制 | 从全部账号生成仓库 JSON、旧版 JSON、旧版简单格式 | 统一使用同一校验与凭证映射；编辑后清除旧预览；简单格式无法表达的字段不再静默丢弃；修复复制按钮与降级处理 |
| 保存浏览器草稿 | 用户主动保存账号草稿到浏览器 | 含账号凭证时先提示明文存储；PAT 加密不会加密账号草稿 |
| 加载 / 清除浏览器草稿 | 恢复草稿或删除持久副本 | 加载覆盖需确认；清除保留当前内存表格、GitHub 设置和远端内容；兼容旧版数组 |
| GitHub 同步 | 展开操作面板 | 按钮名称明确表示入口；展开本身不保存 |
| 从 GitHub 加载 | 读取目标分支公开账号元数据 | 不读回 Secrets / 环境文件；手动加载覆盖前确认；解锁后继续待处理加载；加载后重算分页按钮状态 |
| 确认并保存到 GitHub | 一个 commit 更新账号 JSON 和两个工作流，随后独立上传 Secrets | 私有仓库与明文确认检查、账号合并、变量映射、分支冲突保护、凭证不回传均有模拟 API 验证；全部凭证目标关闭时拒绝丢弃输入的令牌 |
| 保存部分失败 | 文件与 Secrets 非原子事务 | 未全部完成时保留账号草稿和填写的令牌；已解锁 PAT 可用于重试；后台补充 `complete` / `failed_secrets`，区分提醒与真正失败；本地写入失败或凭证缺失也明确标为未完成 |
| Session / 登录字段 | 仅能由旧版 JSON / WebDAV 承载 | GitHub 同步阻止静默删除这些字段；生成仓库 JSON 的说明明确不包含这些旧版字段 |
| WebDAV 同步 / 记住连接信息 | 前者打开面板，后者显式保存连接配置 | 停止输入、切换预设、同步后的隐式持久化；收起再展开不覆盖未保存输入；记住密码前提示明文存储 |
| WebDAV 保存 / 加载 | 整文件覆盖或替换当前草稿 | 操作前确认；错误不会被本地保存状态覆盖；URL 不擅自附加邮箱；不创建目录；与 GitHub 操作互斥，避免连续点击和请求期间修改草稿 |
| 测试 WebDAV / CORS 代理 | PROPFIND 检查目录，按需转发请求 | 修复双重拼接代理；仅支持 HTTPS 代理且使用前确认；404 不再显示成功；`CONFIG_URL` 保留直连地址 |
| WebDAV 凭证复制 | 主动复制配置 URL / 认证值 | 修复未定义按钮变量；提示中的用户名用文本节点插入；账号变化清除旧提示及其内存凭证 |
| 实时签到查询 | 通过配套本地代理访问站点的用户与签到接口 | 明确不是 Actions 历史；Pages 显示限制；支持当前草稿格式、正确的 Bearer / Session 头、月份与接口记录；重复查询只展示最后一次结果 |
| 下载前端源码 ZIP | 下载当前公开仓库源码 | 不再序列化含已填凭证的页面 DOM；下载本身不提供代理或绕过 CORS |
| 首页文档 / 界面源码 | 链接当前公开界面仓库 | 修正文档入口，保留上游作者署名 |

## 后台优先级与兼容性

- 项目账号文件优先；用户明确指定的配置路径不会回退到云端。未指定路径、默认账号文件缺失或为空时，才尝试 `CONFIG_URL` 和旧版 `NEWAPI_ACCOUNTS`。
- 因此，对已有项目账号的 Actions，仅修改 WebDAV 文件不会更换签到账号。推荐使用 GitHub 同步。
- 公开配置文件仅包含 URL、用户 ID、备注、令牌变量名和可选 CF 变量名；真实令牌分开处理。
- `.env` 托管默认关闭，须用户勾选并确认，仅允许私有仓库，写入前再次检查可见性；首次导入文件只能由用户选择并主动保存触发。
- GitHub Secrets 无法读回。替换账号列表不删除已有 Secrets，避免影响其他工作流；旧 Secrets 需用户按实际用途管理。
- 后台请求错误不直接回显 WebDAV 请求异常中的原始内容，避免带出地址中的凭证。

## 存储与发布

PAT 使用 AES-GCM-256；PBKDF2-SHA256 执行 600,000 次，随机生成盐和 IV，附带用途验证数据。
密文只保存在当前浏览器来源；密码、密钥和明文 PAT 不持久化。普通 Cookie 不是更安全的替代方式。
此机制无法防止解锁后的同源恶意脚本、恶意扩展或被篡改页面；也不覆盖独立的账号草稿 / WebDAV 明文存储功能。

Pages 只通过 `scripts/build_pages.py` 的静态白名单构建。新设置与导出模块已加入白名单及工作流；测试与文档不发布到 Pages。
加密库固定校验值保持不变；通过 `.gitattributes` 禁止 vendor 文件换行转换，解决 Windows 检出后的 SRI 失败。
